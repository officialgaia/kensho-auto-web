# kensho-auto-web

[kensho-auto](https://github.com/officialgaia/kensho-auto)（非公開）の結果をスマホで見るための Web アプリです。

- 公開 URL: https://officialgaia.github.io/kensho-auto-web/
- このリポジトリには **HTML / JS / CSS だけ**が入っていて、懸賞データ・トークン・個人情報は一切含みません。
- 初回に GitHub の fine-grained Personal Access Token を入力すると、ブラウザ（localStorage）にだけ保存され、GitHub API 経由で非公開の `kensho-auto` の `data/*.json` を読み書きします。

本体の `kensho-auto/web/` が元のファイルです。変更したら、このリポジトリにもコピーしてください。
